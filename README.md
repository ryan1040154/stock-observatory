# Chipfolio — 本機盤後投資筆記

## 開啟與關閉

雙擊「啟動 Chipfolio.cmd」，會啟動本機服務並以瀏覽器開啟 http://127.0.0.1:47831/ 。不需要帳號，也不會部署到雲端。重複啟動會開啟同一份資料。

關閉瀏覽器後，本機服務仍在背景；雙擊「停止 Chipfolio.cmd」即可結束。重新開機後再次雙擊啟動即可。本機只監聽 127.0.0.1，不開放區域網路連線。

## 資料與備份

交易、自選、行情快取及籌碼觀察儲存在專案 data/chipfolio.sqlite。不要刪除 data 資料夾。沒有帳號隔離；能使用這台電腦及本機程式的人可查看資料。

交易紀錄區可「匯出備份」與「匯入備份（合併）」。匯入相同交易不重複新增；同一編號內容衝突或不合法交易會整批拒絕。JSON 備份包含交易與自選，不包含行情歷史。完整備份請先停止程式，再複製整個 data 資料夾。

既有雲端網站未刪除，也不會與本機同步。若之前在線上輸入過交易，請在原網站匯出 JSON，再於本機匯入。

## 功能及資料來源

新光、中信分帳；買進、賣出、股息；移動平均成本及損益；上市／上櫃盤後行情；三大法人；集保大戶分布；台指期夜盤；費半、Nasdaq 100、TSM、NVDA、AMD、AVGO。沒有券商登入或下單功能。

記帳可離線使用。更新行情需要網路，僅向證交所、櫃買中心、集保、期交所及 Yahoo Finance 查詢市場資料；不傳送你的交易紀錄。查詢個股歷史時會送出該股票代號。來源失敗保留既有快取，首次無資料則顯示未取得。

頁面開啟且可見時每小時查詢，集保快取 12 小時；關閉頁面不會自動累積資料。籌碼歷史從查詢日起保存，沒有補齊過去 5／20 日。美股為非官方 Yahoo 介面；美東 17:00 前不採當日日線。夜盤日期為官方交易歸屬日。請核對各卡片資料日期。

分割、減資、配股不會自動調整；費用需依實收輸入。股息與已實現損益分開。大戶分布變化不直接等同買賣量。

## 開發

使用 Node 24.19（這台電腦啟動器優先使用已安裝的 Codex bundled Node，否則使用 PATH 的 Node）。啟動器本身不需要登入 Codex。搬到其他電腦需安裝相容 Node，並帶上 local-dist、local、lib、app/api、package.json 及 data；日常執行不依賴 node_modules。

```powershell
npm run build
npm start
node node_modules/typescript/bin/tsc --noEmit
node --test tests/portfolio.test.ts tests/local.test.mjs
```

修改前端後要重新 build。舊 Sites 設定保留作歷史參考；本機啟動不使用它們，不要拿移除登入的 API 部署到公開服務。

## 驗證

本機建置及 TypeScript 通過。5 個自動測試通過，包含成本計算、超賣、匯入去重與衝突、版本衝突、跨來源阻擋、重啟後紀錄持續存在。測試使用隔離暫存資料庫。
