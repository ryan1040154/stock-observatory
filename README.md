# Chipfolio — 本機盤後投資筆記

## 開啟與關閉

雙擊「啟動 Chipfolio.cmd」，會啟動本機服務並以瀏覽器開啟 http://127.0.0.1:47831/ 。不需要帳號，也不會部署到雲端。重複啟動會開啟同一份資料。

關閉瀏覽器後，本機服務仍在背景；雙擊「停止 Chipfolio.cmd」即可結束。重新開機後再次雙擊啟動即可。服務只監聽 127.0.0.1 與自動偵測的 Tailscale IPv4。可用環境變數 CHIPFOLIO_TAILSCALE_IP 指定地址；個人地址不寫入程式。手機連上同一個 tailnet 後開啟 http://100.x.x.x:47831/。電腦需保持啟動。任何 tailnet 中有權連到此電腦的裝置都可以使用這份庫存；仍無網站帳號。

若手機無法連入，雙擊「設定手機連線.cmd」，接受 Windows 系統管理員提示後，會新增僅限 Tailscale 介面、100.64.0.0/10 來源與 TCP 47831 的防火牆規則。現有權限無法自動新增此規則。

## 資料與備份

交易、自選、行情快取及籌碼觀察儲存在專案 data/chipfolio.sqlite。不要刪除 data 資料夾。沒有帳號隔離；能使用這台電腦及本機程式的人可查看資料。

交易紀錄區可「匯出備份」與「匯入備份（合併）」。匯入相同交易不重複新增；同一編號內容衝突或不合法交易會整批拒絕。JSON 備份包含交易與自選，不包含行情歷史。完整備份請先停止程式，再複製整個 data 資料夾。

既有雲端網站未刪除，也不會與本機同步。若之前在線上輸入過交易，請在原網站匯出 JSON，再於本機匯入。

## 圖表功能

加權指數卡片的「查看走勢／K 線」提供當日分時、昨收參考線及分段成交金額（億元），來自證交所網站使用的 mis_ohlc_TSE.txt；約每分鐘一點，開啟分時且頁面可見時每十五秒檢查。來源的 ts 時間優先於區段結束時間，避免將未完成分鐘標到未來。

指數日線使用 MI_5MINS_HIST，每月載入，首次取最近六個月，持續合併保存在本機最多 1,500 筆。日線來源不含成交量。今日暫定 K 棒使用 MIS 當日開高低及最新報價，清楚標示尚未以盤後資料確認。

全部 K 線圖表可切日／週／月、收盤走勢、MA5/20/60、成交量（來源有提供才顯示）、20/60/120/全部筆數、放大縮小、歷史滑桿、十字線及觸控／鍵盤查看數值。均線在完整已載入資料上計算後才擷取顯示區段；不足期數留白，最後週／月可能尚未完成。手機可橫向捲動圖表。

分時資料僅有時間點價格，不補造 1/5/15 分鐘 OHLC；未包含技術畫線、逐筆串流或股票盤中行情。

## 功能及資料來源

加權指數卡片使用證交所 MIS 網頁資料介面，每 15 秒查詢一次。只在頁面可見時輪詢，返回頁面會立即查詢；多個裝置共用伺服器的 15 秒快取。免費網頁介面不保證逐筆即時或持續可用。畫面標示來源報價時間及最近查詢時間，盤中來源報價落後超過 90 秒或日期不同會標示未跟上目前時間。失敗保留舊報價，首次失敗使用有標示的收盤備援；盤中指數不會改動庫存損益使用的收盤價。

證券帳戶可自訂新增、改名，無交易帳戶可刪除；新光、中信預設分帳；買進、賣出、股息；移動平均成本及損益；上市／上櫃盤後行情；三大法人；集保大戶分布；台指期夜盤；費半、Nasdaq 100、TSM、NVDA、AMD、AVGO。沒有券商登入或下單功能。

記帳可離線使用。更新行情需要網路，僅向證交所、櫃買中心、集保、期交所及 Yahoo Finance 查詢市場資料；不傳送你的交易紀錄。查詢個股歷史時會送出該股票代號。來源失敗保留既有快取，首次無資料則顯示未取得。

手動「更新資料」直接重新查詢行情、法人、集保與海外來源；自動查詢仍使用一小時／集保十二小時快取。顯示成功擷取時間、查詢時間與快取狀態。來源失敗時保留舊資料，不能將查詢時間當作行情日期。

股價可切換日 K 線與收盤折線，台股及海外 OHLC 以日期合併保存最多 1,500 筆，圖表可自訂顯示筆數。夜盤日線保存最多 240 筆；近月換月可能跳空，不是分鐘線。期交所歷史日期查詢目前回傳查無資料，故從官方最新日線逐日累積，不補造歷史。

頁面開啟且可見時每小時查詢，集保快取 12 小時；關閉頁面不會自動累積資料。籌碼歷史從查詢日起保存，沒有補齊過去 5／20 日。美股為非官方 Yahoo 介面；美東 17:00 前不採當日日線。夜盤日期為官方交易歸屬日。請核對各卡片資料日期。

分割、減資、配股不會自動調整；費用需依實收輸入。股息與已實現損益分開。大戶分布變化不直接等同買賣量。

## 外觀與重新建置

介面採淺色背景及藍色重點色，包含卡片進場、按鈕回饋與數字過渡；系統啟用減少動畫時停用動態效果。修改 app/globals.css、app/investment-dashboard.tsx 或 components 後，雙擊「重建並重啟 Chipfolio.cmd」，會先檢查 TypeScript、建置 local-dist，再停止並啟動本機服務。建置或重啟失敗會顯示錯誤，請勿將未成功重啟當作新版本。

## 開發

使用 Node 24.19（這台電腦啟動器優先使用已安裝的 Codex bundled Node，否則使用 PATH 的 Node）。啟動器本身不需要登入 Codex。搬到其他電腦需安裝相容 Node，並帶上 local-dist、local、lib、app/api、package.json 及 data；日常執行不依賴 node_modules。

```powershell
npm run build
npm start
node node_modules/typescript/bin/tsc --noEmit
npm test
```

修改前端後要重新 build。舊 Sites 設定保留作歷史參考；本機啟動不使用它們，不要拿移除登入的 API 部署到公開服務。

## 驗證

本機建置及 TypeScript 通過。12 個自動測試通過，包含成本計算、超賣、匯入去重與衝突、版本衝突、跨來源阻擋、重啟後紀錄持續存在。測試使用隔離暫存資料庫。
